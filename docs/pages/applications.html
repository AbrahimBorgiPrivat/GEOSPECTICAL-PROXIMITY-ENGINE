Site, Address and Lead Classification

One relation, several decision contexts: coverage, competitive context and lead potential.

Geospatial Proximity EngineApplicationsWeighted network accessibility

The engine is a classification component, not a complete site-selection model. It determines which targets are reachable from each source under a chosen transport profile and radius.

Target weights give the relation a business meaning. A weight may represent population, addresses, revenue potential, store size or category relevance. Because the calculation is consistent, results remain comparable across candidate locations, whether the radius is specified in metres or travel duration.

Lead classification example

The included data assigns each lead one or more sources and a set of residential targets. Each lead is evaluated independently, so routes are never constructed across leads.

The results are collected on one Folium map. Green targets and routes satisfy the network radius; red ones do not. The map provides a visual audit trail alongside the count and weight measures.

Folium map output

The map is generated from the prepared lead data. It combines lead-specific calculations in one overview while preserving each lead's independent source-to-target relations.
