From Candidate Pairs to Weighted Proximity

An exact decision rule, arranged as four deliberately small computational steps.

The procedure first eliminates impossible matches with a proven lower bound, then uses the routed graph only where it can affect the final decision. The output is the accepted relation, its distance evidence and a set of weighted summaries.

The same four steps support a radius stated in metres or duration, with an assumed average speed used to screen time-based candidates before OSRM evaluates their actual travel time.

1. Candidate selection
Keep only pairs with $\delta(s_i,t_j)\leq r$.

The geographic lower bound removes pairs that cannot satisfy the network radius.

↓
2. Directed distance matrix
Evaluate $D_{ij}=d_G(s_i,t_j)$ for candidate pairs.

OSRM supplies the directed source-to-target shortest-path distances.

↓
3. Radius decision
Accept each pair for which $D_{ij}\leq r$.

The implementation uses an inclusive radius boundary; replace $\leq$ with $<$ for a strict policy.

↓
4. Aggregate accepted targets
Count, weight and deduplicate the accepted targets.

Return relation count, sum of weights, unique-target count and unique sum of weights.

Result semantics

The summaries distinguish repeated source–target relations from unique geographic coverage.

MeasureMeaning
Accepted relationsOrdered source–target pairs within the routed radius.
Sum of weightsWeight summed per accepted relation.
Unique targetsDistinct target coordinates reached by at least one source.
Unique sum of weightsWeight counted once per distinct target coordinate.
